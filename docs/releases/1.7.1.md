# DotCov 1.7.1

This patch adds verified TypeScript and Python coverage examples and exercises the badge
action on Windows, Linux, and macOS. Cobertura remains the report format: run your language's
coverage producer first, then pass its XML report to DotCov.

- Real upstream suites produce fresh reports, compared with native per-file and aggregate
  counts. Pinned README badges and published Coveralls results provide same-commit baselines
  for compare-versions, pydash, and peek-readable.
- Pydash has separate real-thread checks for timers, locking, cancellation races, and
  failure detection. Only its two short-sleep tests use a deterministic clock in the full
  coverage run. Peek-readable runs all 29 upstream tests with native timers and async reads.
- Badge checks exercise passing and failing gates against local bare repositories on all
  three platforms. The default installer consumes a locally packed candidate in CI, so
  release validation does not depend on the candidate already being published to NuGet.
- DotCov's own 100% line and branch gate remains mandatory. Its workflow no longer publishes
  a repository `badges` branch; consumers can still use the reusable badge action.

CLI arguments and exit codes are unchanged from 1.7.0. Peek-readable's published counts are
205/209 lines and 54/57 branches. Coveralls combines them into 97.37% (a 97% badge), while
DotCov displays the separate rates as `98.1% / 94.7%`.
