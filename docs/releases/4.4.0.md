# DotCov 4.4.0

The complete repository test suite now uses MSTest 4.5.1 on native
Microsoft.Testing.Platform. Published APIs, CLI behavior, exit codes, and JSON
contracts remain unchanged from 4.3.2.

## Complete test migration

- Preserve all 1,999 existing cases and add two contract tests for the custom
  scenario providers' repeatability, distinct names, permutations, and groupings.
- Use native synchronous and async MSTest assertions, retaining exact exception
  types, exact runtime-type checks, collection ordering, and numeric tolerances.
- Express literal rows, computed rows, and independent combinations with
  `DataRow`, `DynamicData`, and `CombinatorialData`. Immutable stream and merge
  scenarios implement `ITestDataSource` without acquiring live resources.
- Declare method-level parallelism explicitly. `ResourceLock` preserves process
  environment isolation, and cooperative timeouts use `TestContext` cancellation.
- Own each upload server per test using initialization and cleanup, joining it
  before disposing the workspace. The real consuming coverage sample uses MSTest.
- Remove the previous framework dependencies and infrastructure completely.
  No legacy suite, compatibility assertion layer, or backup is retained.

## Coverage and commands

The .NET 10 native runner and coverlet.MTP 10.1.0 remain in place. The measured
assemblies, include/exclude filters, and 100% line and branch thresholds are
unchanged. The repository wrapper now forwards standard MSTest filters:

```sh
dotnet fallout Test --filter 'FullyQualifiedName~DotCov.Tests.ParserContractTests'
dotnet fallout Coverage
```

Test instructions, agent guidance, and release-check examples use these commands.

## Verification

- All 2,001 cases pass locally, with zero skipped tests and 100% line/branch coverage.
- Every original test method retains its discovered case count; only the two new
  scenario-provider contract tests add cases.
- The full JetBrains inspection reports zero findings.
- An isolated native-runner probe records one pass and one deliberate assertion
  failure, exit code 2, and the original failure message in TRX.
- Source, resolved dependencies, and generated framework artifacts contain no
  remaining references to the removed frameworks.

```sh
dotnet tool update -g DotCov.Tool --version 4.4.0
```
