# DotCov 4.1.0

Additions to the 4.0 agent contract; nothing that worked on 4.0 changes. Coming from 3.x, read the
[4.0.0 notes](4.0.0.md) first: the verdict moved to stderr, a failed test run exits 6, and the
JSON was reshaped.

## New

- **`diff` takes the exclusion flags.** `--exclude-generated`, `--exclude-test-code` and `--keep`
  apply to both reports, so a generated file neither appears nor disappears in the comparison.
  Stderr names the exclusion once; JSON carries `excluded` and `exclusionRules`.
- **`--no-color` everywhere.** `check` and `snapshot` accept it too, so a script or agent can pass
  it to every command without a usage error.
- **Rider no longer calls the build's targets unused.** The repository's own `build/Build.cs`
  marks the Target and Parameter properties Fallout uses by reflection with `[UsedImplicitly]`.
  Fallout ships no JetBrains annotations, so this lives in the build script; nothing in the
  packages changes.

## Upgrade

```bash
dotnet tool update -g DotCov.Tool --version 4.1.0
```

Use `ANcpLua/dotcov/.github/actions/badge@v4.1.0` and `DotCov`/`DotCov.Fallout` 4.1.0.
