# DotCov 4.7.1

Toolchain maintenance. CLI behavior, coverage gates, exit codes and JSON output
contracts are unchanged from 4.7.0.

## Maintenance

- Pin the .NET SDK to 10.0.402 in `global.json`.
- Update ANcpLua.Analyzers from 2.1.5 to 2.1.8. The build stays warning-free under
  `TreatWarningsAsErrors`; no source changes or suppressions were needed.
- Remove `TestingPlatformDotnetTestSupport` from the test project. `global.json`
  already selects the Microsoft.Testing.Platform runner, so the VSTest-mode bridge
  was redundant; `dotnet test` and the Fallout targets run the suite natively.

## Verification

- TESTS_PLACEHOLDER
- All four shipping assemblies meet the existing 100% line and branch gates.

## Upgrade

```sh
dotnet tool update -g DotCov.Tool --version 4.7.1
```

Use `ANcpLua/dotcov/.github/actions/badge@v4.7.1` and `DotCov`/`DotCov.Fallout` 4.7.1.
