# DotCov 4.3.1

Repository-hosted agent guidance and a development dependency update. CLI behavior,
coverage gates, exit codes, and JSON output contracts are unchanged from 4.3.0.

## Using DotCov from other repositories

The repository now includes the reusable
[`dotcov` skill](../../.agents/skills/dotcov/SKILL.md). It guides .NET,
TypeScript/JavaScript, and Python coverage collection, applies the consuming
repository's thresholds and source scope, and explains uncovered lines, partial
branches, warnings, exit codes, report comparisons, and .NET CRAP results.

The skill and its collection reference are versioned under `.agents/skills/dotcov/`.
Copy or link that folder into a consuming repository's own `.agents/skills/` for
repository-local discovery.

## CI and release guidance

- The CI skill follows the current event matrices, single-run coverage inputs,
  Pages badge publication, local integration feeds, and concurrency rules.
- The release skill covers versioned notes and package metadata, the complete
  seven-package set with the tool pointer published last, tag versus manual
  dispatch behavior, and verification of the actual published tool.

## Maintenance

Update ANcpLua.Analyzers from 2.1.3 to 2.1.5. The reusable skill is distributed in
the repository and tag; the NuGet packages retain their existing purposes.

## Upgrade

```bash
dotnet tool update -g DotCov.Tool --version 4.3.1
```

Use `ANcpLua/dotcov/.github/actions/badge@v4.3.1` and `DotCov`/`DotCov.Fallout` 4.3.1.
